# 汉语 Flashcards — HSK 3.0

Web app ทายคำศัพท์จีน: โชว์ตัวจีน → เลือกคำแปล (อังกฤษ + พินอิน) จาก 3 ตัวเลือก
ตอนเฉลยมี **radical (部首)** และ **ประโยคตัวอย่างระดับข้อสอบ** พร้อมพินอินและคำแปล

## รัน

```bash
cd public && python3 -m http.server 8000
# เปิด http://localhost:8000
```

ต้องเปิดผ่าน web server (เปิดไฟล์ตรงๆ ด้วย `file://` ไม่ได้ เพราะ `fetch()` โดน CORS บล็อก)
เป็น static site ล้วน — เอาไป deploy บน GitHub Pages / Netlify / Vercel ได้เลยโดยไม่ต้องแก้อะไร

## โครงสร้าง

```
build/build_data.py     สร้างคลังคำศัพท์จาก GitHub
build/sentences.py      จับคู่ประโยคตัวอย่างจาก Tatoeba
build/.cache/           ไฟล์ต้นฉบับที่โหลดมา (gitignored, ~40 MB)
public/index.html
public/css/style.css
public/js/app.js
public/data/index.json  รายการระดับ + จำนวนคำ
public/data/hsk-N.json  ~2.7 MB รวมทุกระดับ (โหลดแยกตามระดับที่เลือก)
```

รูปแบบข้อมูลแต่ละคำ:

```json
{
  "s": "课", "r": "讠", "py": "kè",
  "en": ["subject; course; class", "..."],
  "pos": ["n"], "q": 1461,
  "ex": {
    "zh": "我做完功课，想去睡觉，可是又要上学……",
    "py": "wǒ zuò wán gōng kè， xiǎng qù shuì jiào， kě shì yòu yào shàng xué……",
    "en": "Now that I have finished this assignment I want to go to sleep, but I have to go to school."
  }
}
```

`s` = ตัวย่อ · `r` = radical · `py` = พินอิน · `en` = คำแปล ≤3 ความหมาย
`pos` = ชนิดคำ · `q` = อันดับความถี่ (0 = ไม่มีข้อมูล) · `ex` = ประโยคตัวอย่าง (ไม่มีก็ตัด key ออก)

## หมายเหตุเรื่องคุณภาพข้อมูล

### การเลือกความหมาย

ต้นทางเก็บทุกเสียงอ่านของคำ และ **ไม่ได้เรียงตามความถี่** เช่น 听 ขึ้น `yǐn "smile (archaic)"`
มาก่อน `tīng` สคริปต์เลยให้คะแนนแต่ละเสียงอ่านแล้วเลือกตัวที่ดีที่สุด:

- ตัดความหมายที่ใช้เป็นคำตอบไม่ได้ (`surname X`, `variant of`, `abbr. for`, `CL:`)
- ลดคะแนนเสียงอ่านที่มีแต่ความหมายโบราณ `(archaic)/(old)/(literary)`, ที่เป็นคำเฉพาะ (พินอินขึ้นต้นตัวใหญ่ เช่น 日 `Rì`), และที่เป็นแค่ variant ของตัวอื่น
- เอาความหมายที่ใช้ทั่วไปขึ้นก่อนความหมายโบราณ

เหลือ 多音字 อีกกลุ่มที่ heuristic ตัดสินไม่ได้ (长 cháng/zhǎng, 重 zhòng/chóng, 空 kōng/kòng ฯลฯ)
ใช้ตาราง `OVERRIDES` ใน `build_data.py` กำหนดตรงๆ — เพิ่มได้ถ้าเจอคำที่เลือกเสียงอ่านผิด

### การเลือกประโยคตัวอย่าง

จาก 65,307 ประโยคที่มีคำแปลอังกฤษ (แปลงตัวเต็ม→ตัวย่อแล้ว ไม่ทิ้ง — เพิ่ม coverage จาก 70% เป็น 79%)
ให้คะแนนแล้วเลือกประโยคที่ดีที่สุดของแต่ละคำ:

- **ความยาว 15–28 ตัวอักษร** ได้คะแนนสูงสุด · ตัดประโยคที่สั้นกว่าคำเป้าหมาย +3 ตัว ออกเลย (เช่น 我很好。 ง่ายเกิน)
- **บวกคะแนนถ้ามี 2 อนุประโยค** (มีลูกน้ำ) — อ่านเป็นภาษาข้อสอบมากกว่าประโยคหนังสือฝึกหัด
- **ลบคะแนนต่อตัวอักษรที่ไม่อยู่ในคลัง HSK** — กันประโยคที่มีคำแปลกจนอ่านไม่ออก
- ประโยคที่คะแนนไม่ถึงเกณฑ์ถือว่าไม่มีตัวอย่าง ดีกว่าโชว์ประโยคแย่ ๆ
- **เช็คเสียงอ่านในบริบท** ด้วย pypinyin: 都 สอน `dōu` ประโยคที่ใช้ 都市 (`dū`) จะถูกข้ามไปหาประโยคถัดไป เทียบแบบไม่สนวรรณยุกต์เพื่อให้ tone sandhi (不 `bù`→`bú`) ไม่นับเป็นไม่ตรง

ตรวจแล้วทั้ง 7,336 ประโยคไม่มีข้อไหนเสียงอ่านไม่ตรงกับที่การ์ดสอน

Coverage ประโยคตัวอย่างต่อระดับ:

| HSK | 1 | 2 | 3 | 4 | 5 | 6 | 7-9 | รวม |
|---|---|---|---|---|---|---|---|---|
| คำ | 294 | 197 | 487 | 971 | 1,546 | 1,684 | 4,871 | 10,050 |
| มีตัวอย่าง | 96% | 96% | 98% | 94% | 92% | 82% | 55% | **73%** |

คำที่ไม่มีประโยค (ส่วนใหญ่เป็นคำเฉพาะทางใน 7-9) จะซ่อนช่องตัวอย่างไปเลย

> ประโยคเป็นประโยคจริงจาก Tatoeba ที่คัดให้ยากระดับข้อสอบ **ไม่ใช่ประโยคจากข้อสอบ HSK จริง**

### การเลือกตัวลวง

ตัวลวงสุ่มจากระดับเดียวกัน (ถ้าระดับนั้นมี ≥40 คำ) และตัดออกถ้าข้อความที่แสดงซ้ำกัน
คำแปลแรกซ้ำกัน หรือมีคำภาษาอังกฤษยาว ≥4 ตัวอักษรซ้ำกับตัวเลือกอื่น
ในโหมดพินอินบังคับให้ทุกตัวเลือกมีจำนวนพยางค์เท่ากันด้วย ไม่ให้เดาจากความยาว

ทดสอบครบทั้ง 10,050 คำ × 3 โหมด: ไม่มีข้อไหนได้ตัวเลือกซ้ำหรือไม่ครบ 3 ตัว
